# Chennai Marina Boys V6

Cinematic React + Three.js team website.

## Features
- 3D crest homepage with real WebGL, bloom and scroll-controlled motion
- Scroll-controlled GPU championship photo transition
- Searchable TNPL-NZ Season 7 schedule, filter by matchday
- Responsive squad grid with player search, category filters and animated full-screen profile dialogs (Escape / arrow keys)
- Gallery, sponsors, reduced-motion support, responsive layouts

## Run

```bash
npm install
npm run dev
```

Production check: `npm run build`.

## Data caveats
Fixture details are transcribed from the user-provided screenshot, not a live feed; verify against the tournament's official schedule before publishing. Player names/roles, jersey numbers and photos were matched from supplied photos and previous project data. Names or roles that could not be independently verified should be checked with team management. No statistics are fabricated.
