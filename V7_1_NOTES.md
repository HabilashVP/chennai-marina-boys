# V7.1 Gold Brush + Scores

- No sound generation or controls.
- Gold paintbrush cursor with drifting dust. Desktop only; respects reduced motion.
- Upcoming match countdown switches to next start time and uses Pacific/Auckland time zone. Fixtures must be maintained in main.jsx.
- CricClubs link opens TNPLNZ; this patch does not claim to retrieve live scores automatically.
- No additional npm packages.

Installation: extract patch in project root, npm run build, npm run dev; commit src/main.jsx src/V7Experience.jsx src/GoldDustCursor.jsx src/v7.css.
